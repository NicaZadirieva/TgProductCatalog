# TelegramBot для работы с каталогом товаров

## Запуск

### Production
make prod

### Development
make dev

## Настройка .env

- TELEGRAM_BOT_TOKEN=token # token от BotFather
- EVIRONMENT=development # development/production
- BACKEND_URL=host:port # URL к API FastAPI
- MINI_APP_URL=https:// # URL к nextjs
